# 제주 바다 탐사 연구소 (돌고래의 편지)

학교자율시간 「데이터와 인공지능」 8차시 탐구 수업용 웹앱입니다.
서귀포 남방큰돌고래의 편지에서 출발해 수온 데이터와 바닷속 사진으로 제주 바다의 문제를 찾고,
티처블 머신(또는 내장 AI)으로 바다 지킴이 탐사선을 만들어 봅니다.

- 바로 쓰기: https://gwondol3-dotcom.github.io/jeju-dolphin-letter/
- 수온 기록과 사진은 수업을 위해 만든 가상 데이터입니다.
- 사진 카드, 편지, 봉투 등의 교구 그림은 함께 연구한 선생님들이 만든 자료입니다.
- 학생 기록은 각자 브라우저(localStorage)에만 저장되고 서버로 보내지지 않습니다.
